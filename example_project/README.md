# 范例工程

这是从真实骑行工程整理出的可公开范例，可直接在仓库根目录运行：

```bash
ride-overlay example_project --preview
```

工程不包含源视频，因此图形编辑器的视频列表和连接信息保持为空。`config.json` 的命令行截取范围为前 600 秒，便于快速生成覆层测试视频。

`example_activity.fit` 保留原始运动时长和传感器曲线，但经纬度已统一平移到虚构位置，时间轴已整体平移到固定日期，设备序列号已移除，活动名称也已替换。它不应被当作真实地理或时间数据使用。
